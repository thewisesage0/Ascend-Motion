# Routes

This project uses TanStack Router file-based routing with Vite. Each `.tsx` file in this directory defines a route. `routeTree.gen.ts` is generated by the TanStack Router Vite plugin; do not edit it by hand.

| File | URL |
| --- | --- |
| `index.tsx` | `/` |
| `about.tsx` | `/about` |
| `contact.tsx` | `/contact` |
| `privacy.tsx` | `/privacy` |
| `services.tsx` | `/services` |
| `start-project.tsx` | `/start-project` |
| `terms.tsx` | `/terms` |
| `work.tsx` | `/work` |
| `work.$slug.tsx` | `/work/:slug` |
